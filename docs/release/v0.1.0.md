# FastWisper 0.1.0

<!-- Draft for the GitHub release page (English). The release workflow attaches this file as the release body. -->

First public release of FastWisper: local push-to-talk voice dictation in Portuguese and English for Omarchy/Hyprland. Hold **Alt+Space**, speak, let go, and the text lands in the app you were using. Speech recognition runs on your machine; nothing is stored by default.

## Highlights

- **Local dictation:** Whisper (whisper.cpp) on any Vulkan GPU or on the CPU, transcribing Portuguese and English as spoken, never translated.
- **Optional local LLM:** your own Ollama on loopback tidies up the text; on any failure or timeout the built-in rules text is used, so dictation never fails because of the LLM. A remote provider is opt-in only and receives text only.
- **Safe pasting on Hyprland:** the target window is revalidated before pasting; when that is not safe, the text is only copied. FastWisper never presses Enter unless you turn on the opt-in "send now".
- **Recording pill, bar plugin and notifications** for the Omarchy shell, plus start/stop sounds.
- **Configuration hub** (Tauri) with live settings, usage metrics, dictionary/snippets/style, themes and an English or Brazilian Portuguese interface; every option also has a `fastwisper config` equivalent.
- **Editable shortcuts** with conflict checks, **VRAM profiles** with game detection, and experimental opt-in **voice notes**.
- **Automatic installer** with rollback and uninstall that keep your config, models and external edits.

See the [changelog](https://github.com/rodrigo-devv/FastWisper/blob/v0.1.0/CHANGELOG.md) for the full list.

## Requirements

- Omarchy with Hyprland 0.56+ (Lua config), Wayland, PipeWire/WirePlumber and a working microphone.
- `vulkan-icd-loader`, plus a Vulkan driver for GPU transcription (`vulkan-radeon`, `vulkan-intel` or `nvidia-utils`); without a usable GPU, FastWisper runs on the CPU.
- `wl-clipboard`, `libnotify` and `jq`.
- Optional: `webkit2gtk-4.1` for the hub, and [Ollama](https://ollama.com) with a local model (we recommend `qwen3:4b-instruct`) for LLM formatting.

```bash
sudo pacman -S --needed pipewire vulkan-icd-loader wl-clipboard libnotify jq webkit2gtk-4.1
```

## Install from the tarball

The tarball contains prebuilt `fastwisper`, `fastwisperd` and `fastwisper-hub` binaries (built with Vulkan on Arch Linux), the Omarchy integration and an installer that installs them without compiling. Run it from a terminal inside your Hyprland session, with `~/.local/bin` on your `PATH`:

```bash
gh release download v0.1.0 --repo rodrigo-devv/FastWisper   # or download both files from this page
sha256sum -c SHA256SUMS
tar -xzf fastwisper-0.1.0-x86_64-linux.tar.gz
cd fastwisper-0.1.0-x86_64-linux
./install.sh
fastwisper doctor
```

`sha256sum -c` must print `OK` before you extract anything. The installer runs `fastwisper setup`, downloads the pinned speech model (verified by SHA-256), enables the user service and wires up the shortcuts, bar, pill and hub. Options: `--offline`, `--no-activate`, `--no-hub`. Keep the extracted folder: `packaging/omarchy/rollback.sh` and `packaging/omarchy/uninstall.sh` inside it undo the installation.

To build from source instead (Vulkan by default, or CPU-only), follow the [README](https://github.com/rodrigo-devv/FastWisper/blob/v0.1.0/README.md#install).

## Known limitations

- Ollama runs as a separate process outside the daemon's Landlock network restrictions; FastWisper turns Ollama's cloud features off by default but cannot guarantee Ollama's own network isolation.
- Daily use has only been on one machine (NVIDIA + Vulkan, USB microphone). AMD, Intel and CPU-only setups are covered by tests, not by daily use; the pill has not been tried on multi-monitor setups, other scale factors or a bottom bar.
- Shortcuts with letters or punctuation assume a US/ABNT2 key position; other layouts are not validated.
- "Send now" waits a fixed ~200 ms between the paste and the Enter, and cancelling does not interrupt that window.
- Deleting history or notes cannot guarantee physical removal on SSDs, backups or snapshots.
- The hub has not been verified with a screen reader or keyboard-only navigation yet.

The full list is in the README under [Known limitations](https://github.com/rodrigo-devv/FastWisper/blob/v0.1.0/README.md#known-limitations).
